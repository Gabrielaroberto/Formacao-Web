# Yoga Life Studio

Website responsivo desenvolvido no âmbito de um projeto de formação em desenvolvimento web.

## Sobre o projeto

O Yoga Life Studio é um website institucional para um estúdio de yoga. O objetivo é apresentar o espaço, divulgar as aulas, disponibilizar horários e facilitar o contacto com os interessados.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3

## Funcionalidades

- Página inicial com apresentação do estúdio
- Informação sobre aulas de yoga
- Consulta de horários
- Formulário de contacto
- Navegação entre páginas
- Layout responsivo
